什么是酷吧 / CBE 应用？

酷吧（Coolbar）是功能手机上的应用平台。.CBE 文件封装 ARM/Thumb 可执行代码与场景、地图、图片、音频等资源，通过固件服务运行。不同设备和 SDK 分支的格式、字节序与屏幕规格存在差异；支持范围以兼容性记录为准。

核心特性

真实执行，而非资源预览

🧠

真实 ARM 执行

大小端 ARM/Thumb 解释执行，含 interworking 分支与编译器跳转表，运行真实客机代码。

🔌

固件服务桥

内存、屏幕、输入、定时器、UCS2 文本、下载/支付等 20+ 服务组，逐调用可追踪。

🎵

音频引擎

WAV/MP3 解码与 MIDI 合成，44.1 kHz 立体声混音，音量可调并输出确定性诊断。

💾

存档与内存

校验和存档、共享重置，并通过 libretro 向前端暴露客机内存与屏幕缓冲。

🕹️

桌面体验

4 种缩放滤镜、按键重映射、虚拟手柄 overlay、全屏/音量/headless。

🧩

RetroArch 核心

RGB888 输出、RetroPad 映射、指针/触摸输入、音频与存档，即插即用。

快速开始

🖥️ 桌面运行

  1. 从 Releases 下载对应平台二进制
  2. coolbaremu game.CBE
  3. 方向键移动 · Enter 确认 · Q/E 软键 · R 重置

🎮 RetroArch

  1. 下载 libretro 核心并放入 cores/
  2. 放入 coolbaremu_libretro.info 到 info/
  3. Load Core → Load Content

🔨 从源码编译

  1. git clone https://github.com/AloysHF/CoolbarEmu.git
  2. cargo build -p coolbaremu --release
  3. cargo build -p coolbaremu-libretro --release
无需安装 · 浏览器直接运行
